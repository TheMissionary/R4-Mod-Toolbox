* Engineered Rust Atomic Load Engine (apply_archive_profile): Discovers archives on disk, reconciles active vs disabled state, auto-disables unknown/new mods, rewrites modlist.txt from snapshot, and executes a fresh integrity audit scan.

### Milestone 21: Top-Placement for New Mods, Category Counts, & Windows Symbol Support
* Top-Placement: Inverted ordered_paths in scan_archives so files detected on disk that are not in modlist.txt are prepended to index 0 ("Uncategorized" above all categories).
* Nested Mod Count Badges: Svelte $derived reactive map (categoryCounts) computing count of mods in each category, passed to CategoryDelimiterRow as (N mods) in both expanded and collapsed states.
* Windows Symbol Support: Replaced restrictive alphanumeric category filter with a check against 9 Windows-forbidden filename characters (< > : " / \ | ? *), allowing brackets [], parentheses (), hyphens, hashtags, etc.
* Fixed delimiter parsing using Rust's exact strip_prefix("[CAT] ") and strip_suffix(".archive") to prevent character-mangling bugs.
* Rebranded UI text from "Archive Profiles" to "Custom Archive Presets".

### Milestone 22: Developer Tile Branding & Home Dashboard Default Launch
* Replaced legacy CP77 version indicator in bottom-left sidebar with custom Mi55ionary Developer Tile.
* Integrated hand-drawn orange heart avatar SVG (#e08528), developer label, and working external links to Nexus Mods profile and GitHub repository via Tauri opener plugin.

## 3. Critical Architectural Learnings & Svelte 5 Protocols

1. **Windows Minimized Coordinates (-32000) Off-Screen Trap:**
   * When closed while minimized, Windows reports window coordinates as -32000, -32000. If persisted blindly to config.json, the window launches off-screen in the void. Must enforce boundary validation (x > -1000 && y > -1000) before saving or restoring window positions.
2. **Git Source Control Hygiene:**
   * Never track compiled binaries (*.exe, *.dll) in source control. Stored .gitignore must explicitly ignore *.exe to prevent repository bloat; binaries belong in GitHub Releases.
3. **Markdown Stream Buffer Thresholds in Web UIs:**
   * Single markdown code blocks exceeding ~1,200–1,500 lines can crash the DOM/parser in web chat UIs, stripping formatting containers and copy buttons. Multi-file deliveries must be broken into discrete, atomic script blocks (<800 lines).
4. **Safe Delimiter String Stripping:**
   * Never use trim_start_matches with a string set in Rust, as it strips any character in the set (e.g. "[CAT] " strips 'C', 'A', 'T'). Use exact strip_prefix and strip_suffix.
