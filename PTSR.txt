## 2. Project History, Milestones & Validated Architecture

### Core Functionality in Baseline-20260926-ContextMenuComplete
1. Red4lib In-Memory Hash Scanner:
   * Non-destructive parsing of .archive file resource headers.
   * Compares 64-bit resource hashes across archives to calculate a real-time conflict matrix identifying exact overlapping hashes.
   * Differentiates winning archives from overridden archives according to active load order position.
2. Interactive Conflict Drawer:
   * Summarizes all contested archives.
   * Clicking a contested mod smoothly scrolls to the item in the main load list and triggers a green pulse highlight (registerModNode).
3. Four-Tier Native Context Menu:
   * Right-click trigger on both archive rows and companion .XL badges.
   * Actions: Reveal in Windows Explorer, Enable or Disable mod (toggling .disabled extension), and Copy File Name to clipboard with visual feedback.
4. Drag-and-Drop Reordering Engine:
   * Full drag-and-drop support with real-time insertion line indicators (dropPlacement: 'before' | 'after').
   * Commits the active sequence directly into REDengine's native modlist.txt.
5. Companion .XL Pairing:
   * Automatically pairs companion .xl files with their parent archives (via explicit map or pattern matching .archive.xl / <stem>.xl).
   * Toggles .xl active state synchronously whenever the parent .archive is enabled or disabled.

### Operational Infrastructure & Handoff Protocols
1. AI Studio Full-File Delivery Paradigm:
   * All code generation in Google AI Studio provides complete, pristine file payloads or whole new sub-component files.
   * Terminal-based regex and Node.js string-replacement scripts (scripts/update-*.mjs) are abandoned to eliminate AST anchor slicing failures.
2. Git-First Version Control:
   * The active repository G:\R4-Mod-TBX is initialized to track every validated milestone.
   * Instant rollback via git reset --hard or git restore . maintains workspace stability without recursive folder duplication.
   * Working tree must be confirmed clean before and after each variable change.
3. Component Modularization Strategy:
   * In Baseline-20260926-ContextMenuComplete, standard mod rows remain inline within ArchiveView.svelte.
   * New UI features must be developed as dedicated sub-components in src/lib/components/ (specifically CategoryDelimiterRow.svelte), keeping ArchiveView.svelte changes restricted to clean template branching.
